Мои Пет-Проекты

Здесь представлены мои работы, созданные в рамках курсов CS50's Web Programming with Python and JavaScript и CS50x. Проекты демонстрируют навыки работы с Django, базами данных, HTML, CSS и JavaScript.

CS50W Final Project: Interactive Tournament Bracket (Django/JavaScript)

**Динамическое веб-приложение для создания и управления турнирными сетками (турнирные таблицы).** Проект отличается высоким уровнем сложности: реализован полностью интерактивный интерфейс, где пользователи могут выбирать победителей в матчах, и прогресс сохраняется в бэкенде.

**Особенности и сложность:** Сложная логика работы с БД (4 взаимосвязанные модели Django) для точного отслеживания состояния каждого участника. Реализована уникальная система обработки группового этапа для турниров на 32 участника. Фронтенд организован модульно (отдельные JS-файлы для каждого раунда) для лучшей поддерживаемости.

**Ключевые технологии:** Django (Backend State Management), Modular JavaScript, ORM, JSON Handling.

Finance (CS50x) (Flask/JavaScript)

Веб-приложение для симуляции **управления акциями** и финансового портфеля. Проект демонстрирует навыки работы с **базами данных** и **внешними API** для получения актуальных данных о ценах акций.

**Ключевые особенности:** Реализованы функции покупки, продажи акций, просмотра истории транзакций и текущего баланса. Проект требует четкого управления пользовательскими **сессиями** и безопасного хранения данных.

**Ключевые технологии:** Python (Flask), **SQL (SQLite)**, **API** (получение котировок), Jinja (шаблонизация), Session Management.
